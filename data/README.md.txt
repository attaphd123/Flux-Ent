# Datasets

This folder contains the small example networks used in the paper.

- `toy.txt` – 14‑node toy network (illustrative example)
- `karate.txt` – Zachary's karate club (34 nodes, 78 edges)

The larger networks (Air‑traffic, Ca‑netscience, Ca‑GrQ, Moreno‑blogs, FB‑Politician) used in the experiments are available from public repositories:

- https://networkrepository.com/

After downloading, place the edge list files (space‑separated, node IDs integers) in this folder and update the file paths in your script.
